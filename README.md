# Property Listings API

A public, read-mostly REST API for a Nigerian residential property market: estate agencies, the
agents who work for them, the properties those agents list for sale or rent, and viewing requests
made against those listings.

> Status: resource design (Step 1). Endpoint documentation, run instructions, and evidence are
> added as each step is built.

## Resource design

Four resources. Each one references the one above it:

```
agencies 1 ──< agents 1 ──< listings 1 ──< viewings
```

- An **agency** employs many agents.
- An **agent** belongs to exactly one agency and manages many listings.
- A **listing** is managed by exactly one agent and receives many viewing requests.
- A **viewing** is a request by a member of the public to see one listing at one time.

Every identifier is a UUID (v4), generated by the database on insert, never a sequential integer.

### `agencies`

| Field          | Type        | Required | Notes                                  |
| -------------- | ----------- | -------- | -------------------------------------- |
| `id`           | uuid        | yes      | generated                              |
| `name`         | string      | yes      |                                        |
| `city`         | string      | yes      | filterable                             |
| `state`        | string      | yes      | filterable (Nigerian state)            |
| `phone`        | string      | yes      |                                        |
| `email`        | string      | yes      |                                        |
| `foundedYear`  | integer     | yes      | 1950 to the current year, sortable     |
| `createdAt`    | ISO 8601    | yes      | sortable                               |
| `updatedAt`    | ISO 8601    | yes      |                                        |

### `agents`

| Field             | Type     | Required | Notes                                  |
| ----------------- | -------- | -------- | -------------------------------------- |
| `id`              | uuid     | yes      | generated                              |
| `agencyId`        | uuid     | yes      | references `agencies.id`, filterable   |
| `fullName`        | string   | yes      | sortable                               |
| `email`           | string   | yes      | unique                                 |
| `phone`           | string   | yes      |                                        |
| `yearsExperience` | integer  | yes      | 0 or more, filterable, sortable        |
| `createdAt`       | ISO 8601 | yes      | sortable                               |
| `updatedAt`       | ISO 8601 | yes      |                                        |

### `listings`

| Field          | Type     | Required | Notes                                                        |
| -------------- | -------- | -------- | ------------------------------------------------------------ |
| `id`           | uuid     | yes      | generated                                                    |
| `agentId`      | uuid     | yes      | references `agents.id`, filterable                           |
| `title`        | string   | yes      |                                                              |
| `description`  | string   | yes      |                                                              |
| `listingType`  | enum     | yes      | `sale` or `rent`, filterable                                 |
| `propertyType` | enum     | yes      | `apartment`, `duplex`, `bungalow`, `terrace`, `land`, filterable |
| `status`       | enum     | yes      | `active`, `under_offer`, `sold`, `let`, filterable           |
| `priceMinor`   | integer  | yes      | price in minor units (kobo), sortable, range-filterable      |
| `currency`     | string   | yes      | ISO 4217 code, always `NGN` in this dataset                  |
| `bedrooms`     | integer  | yes      | 0 or more (0 for land), sortable, filterable                 |
| `bathrooms`    | integer  | yes      | 0 or more                                                    |
| `address`      | string   | yes      |                                                              |
| `city`         | string   | yes      | filterable                                                   |
| `state`        | string   | yes      | filterable                                                   |
| `listedAt`     | ISO 8601 | yes      | when the property went on the market, sortable (default)     |
| `createdAt`    | ISO 8601 | yes      |                                                              |
| `updatedAt`    | ISO 8601 | yes      |                                                              |

### `viewings`

| Field            | Type     | Required        | Notes                                                    |
| ---------------- | -------- | --------------- | -------------------------------------------------------- |
| `id`             | uuid     | yes             | generated                                                |
| `listingId`      | uuid     | yes (on create) | references `listings.id`                                 |
| `requesterName`  | string   | yes (on create) |                                                          |
| `requesterEmail` | string   | yes (on create) | valid email                                              |
| `scheduledFor`   | ISO 8601 | yes (on create) | must be in the future                                    |
| `status`         | enum     | yes             | `requested` (default), `confirmed`, `cancelled`, `completed` |
| `notes`          | string   | no              | nullable                                                 |
| `createdAt`      | ISO 8601 | yes             |                                                          |
| `updatedAt`      | ISO 8601 | yes             |                                                          |

A listing cannot have two non-cancelled viewings booked for the same time. The database enforces
this with a partial unique index, not a check in application code.

### Planned endpoints

All paths are versioned under `/api/v1`.

| Method | Path                               | Purpose                           |
| ------ | ---------------------------------- | --------------------------------- |
| GET    | `/api/v1/agencies`                 | list agencies                     |
| GET    | `/api/v1/agencies/:id`             | one agency                        |
| GET    | `/api/v1/agencies/:id/agents`      | agents at one agency (nested)     |
| GET    | `/api/v1/agents`                   | list agents                       |
| GET    | `/api/v1/agents/:id`               | one agent                         |
| GET    | `/api/v1/agents/:id/listings`      | listings managed by one agent     |
| GET    | `/api/v1/listings`                 | list listings                     |
| GET    | `/api/v1/listings/:id`             | one listing                       |
| POST   | `/api/v1/viewings`                 | request a viewing                 |
| GET    | `/api/v1/viewings/:id`             | read one viewing                  |
| PATCH  | `/api/v1/viewings/:id`             | reschedule, confirm, or cancel    |
| DELETE | `/api/v1/viewings/:id`             | remove a viewing                  |
